# Stop Mobile

Exit mobile / text-to-speech mode. The user is back at a desktop and reading on
a full screen, so optimize for the eye again.

Return to your normal style: use headers, links, URLs, file paths, code blocks,
inline code, tables, and lists wherever they make the answer clearer. You no
longer need to cram everything into the final message — normal formatting and
structure are welcome.

Confirm in one short line that you are back to desktop style, then continue
normally.
